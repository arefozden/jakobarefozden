NDLA topic reference
LESSON 01

Project planning

Understand

Define audience, problem, requirements, deliverables and acceptance criteria. Divide roles and schedule milestones while keeping a shared record of decisions.

Try it yourself

Create a brief for an accessible school information website.

Knowledge check: What is an acceptance criterion?

A measurable condition for accepting a result.

LESSON 02

Website project

Understand

Combine semantic HTML, responsive design, original media, accessibility, privacy and Git version control. Test on different screens and document sources.

Try it yourself

Build a three-page fictional school club website with no personal data.

Knowledge check: Why use semantic headings?

They help navigation and accessibility.

LESSON 03

Network project

Understand

Combine equipment planning, IP addressing, security and documentation. Design for realistic user needs and prepare a fault-finding procedure.

Try it yourself

Design a ten-device media lab with a guest network and budget categories.

Knowledge check: What should an IP plan prevent?

Address conflicts and unclear addressing.

LESSON 04

Media project and evaluation

Understand

Combine storyboard, recording, editing or streaming, rights management and technical quality checks. Evaluate results against criteria and explain improvements using evidence.

Try it yourself

Produce a short offline technical explainer and submit a reflection.

Knowledge check: What makes evaluation useful?

Evidence linked to requirements and actionable improvements.
