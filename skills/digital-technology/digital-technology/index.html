LESSON 01

Analog and digital

Understand

Analog values vary continuously; digital representations use discrete values. A microphone converts sound to an electrical signal, then an ADC samples and quantizes it. Higher sampling frequency and bit depth can improve fidelity but require more storage.

Try it yourself

Compare a smooth waveform with sampled points using the lab.

Knowledge check: What does quantization do?

Maps measured amplitudes to discrete levels.

LESSON 02

Binary and units

Understand

A bit has two possible values. Eight bits form a byte. Binary 101010 equals 32 + 8 + 2 = 42. Decimal KB is 1000 bytes while KiB is 1024 bytes. Hexadecimal groups four bits per digit.

Try it yourself

Represent 42 and 255 with eight bits.

Knowledge check: How many values can eight bits represent?

256.

LESSON 03

Digital media and digitisation

Understand

Pixels represent image colours; RGB often uses 8 bits per channel. Audio samples describe amplitude over time. Lossless compression preserves data while lossy compression trades fidelity for size. Digitisation converts analog material; digitalisation changes workflows using digital technology.

Try it yourself

Calculate uncompressed size of a 1920 × 1080 RGB image and compare with a JPEG.

Knowledge check: Why is a JPEG often smaller?

Lossy compression removes some information.

LESSON 04

Computer systems

Understand

Input devices collect data, processors execute instructions, memory holds working data and output devices present results. Operating systems manage hardware, files, processes and permissions. Applications use OS services.

Try it yourself

Trace typing a letter through keyboard, OS, application and display.

Knowledge check: What happens to unsaved data when power is lost?

Data held only in volatile RAM is lost.

LESSON 05

Logic and processing

Understand

AND requires both inputs, OR requires at least one and NOT reverses a value. CPUs execute instructions through fetch, decode and execute cycles. Clock speed alone does not determine performance.

Try it yourself

Construct truth tables and test the logic lab.

Knowledge check: What is AND with inputs 1 and 0?

0.

LESSON 06

Computer components

Understand

A motherboard connects components; CPU executes instructions, GPU handles parallel workloads, RAM holds active data and SSD or HDD stores persistent data. PSU supplies power and cooling removes heat. Compatibility includes sockets, memory type, power and physical space.

Try it yourself

Choose components for an office PC and a video editing PC; justify decisions.

Knowledge check: Which component retains files without power?

SSD or HDD.

LESSON 07

Troubleshooting hardware

Understand

Start with symptoms and simple checks before changing components. Check power, cables, resource usage and temperatures using approved tools. Shut down and follow ESD procedures before handling internal hardware; never open a power supply.

Try it yourself

Make a diagnostic checklist for a slow PC.

Knowledge check: Why change one variable at a time?

To identify the cause reliably.
