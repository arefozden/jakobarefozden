React

Components, state, props and building interactive interfaces.

React builds interfaces from reusable components. Props pass information into components and state represents changing values. Rendering should be derived from state; effects are useful for synchronising with external systems.

Practical example

function Greeting({ name }) {
  return <h2>Hello, {name}</h2>;
}

Laravel

MVC structure, routes, controllers, views and server-side application development.

Laravel is a PHP framework with routing, controllers, Blade views and database tools. MVC separates presentation, request handling and data responsibilities. Server-side validation and authorisation remain essential.

Practical example

Route::get("/hello", function () {
    return view("hello");
});

Application architecture

Separating concerns, reusable components, APIs and maintainable code.

Maintainable architecture separates responsibilities. UI components display information, application logic validates and transforms it, and data services communicate with storage or APIs. Choose a framework according to complexity rather than fashion.

Practical example

UI → application logic → data service → API/database
