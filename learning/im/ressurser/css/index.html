Koble CSS til HTML

En ekstern CSS-fil kobles vanligvis til HTML-dokumentet inne i <head>. 

<link rel="stylesheet" href="style.css">

En enkel CSS-regel

En CSS-regel består vanligvis av en selector, en egenskap og en verdi. 

p {
    color: blue;
    font-size: 18px;
}

Her velger p alle avsnitt, mens color og font-size bestemmer hvordan teksten skal se ut.

Element selector

En element selector velger alle HTML-elementer av en bestemt type. 

h1 {
    color: blue;
}

Class selector

En class kan brukes på flere HTML-elementer. I CSS skrives class-navnet med punktum foran. 

.card {
    padding: 20px;
    border: 1px solid #ddd;
}

I HTML kan klassen brukes slik: 

<div class="card">
    Innhold
</div>

ID selector

En ID skal normalt være unik på siden. I CSS bruker vi # foran ID-navnet. 

#overskrift {
    color: red;
}

Hover

:hover kan brukes når et element skal endre utseende når musepekeren er over det. 

a:hover {
    color: blue;
}

Farger

Farger kan blant annet skrives som navn, HEX-verdier eller RGB-verdier. 

h1 {
    color: #2563eb;
}

body {
    background-color: #f5f7fb;
}

Tekst

CSS kan styre blant annet skrifttype, størrelse, tykkelse og linjeavstand. 

p {
    font-family: Arial, sans-serif;

    font-size: 18px;

    font-weight: 400;

    line-height: 1.7;
}

Tekstjustering

h1 {
    text-align: center;
}

Box model

HTML-elementer kan tenkes som bokser. CSS box model består av innhold, padding, border og margin. 

.card {
    margin: 20px;

    padding: 24px;

    border: 1px solid #ddd;
}

Margin

margin lager plass utenfor elementet. 

.card {
    margin: 20px;
}

Padding

padding lager plass mellom innholdet og kanten på elementet. 

.card {
    padding: 24px;
}

Border og border-radius

.card {
    border: 1px solid #ddd;

    border-radius: 12px;
}

Flexbox

Flexbox brukes til å plassere elementer i en fleksibel rad eller kolonne. 

.container {
    display: flex;
}

Gap

gap lager mellomrom mellom elementene. 

.container {
    display: flex;

    gap: 20px;
}

justify-content

justify-content bestemmer plasseringen langs hovedaksen. 

.container {
    display: flex;

    justify-content: space-between;
}

align-items

align-items bestemmer plasseringen langs den andre aksen. 

.container {
    display: flex;

    align-items: center;
}

CSS Grid

Grid passer godt når innhold skal organiseres i rader og kolonner. 

.container {
    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;
}

Tre like kolonner

repeat(3, 1fr) lager tre kolonner med lik bredde. 

grid-template-columns:
    repeat(3, 1fr);

Én kolonne

På mindre skjermer kan Grid for eksempel endres til én kolonne. 

grid-template-columns: 1fr;

Responsive design

Responsive design betyr at nettsiden tilpasser seg forskjellige skjermstørrelser.

Media queries kan brukes til å endre CSS når skjermen blir mindre. 

@media (max-width: 800px) {

    .card-grid {
        grid-template-columns: 1fr;
    }

}

Max-width

max-width kan hindre innholdet i å bli for bredt på store skjermer. 

main {
    max-width: 1200px;

    margin: 0 auto;
}

Et enkelt eksempel

Her kombineres flere av teknikkene fra denne siden. 

.card {
    padding: 24px;

    background-color: white;

    border: 1px solid #ddd;
    border-radius: 12px;
}

.card-grid {
    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;
}

@media (max-width: 800px) {

    .card-grid {
        grid-template-columns: 1fr;
    }

}
