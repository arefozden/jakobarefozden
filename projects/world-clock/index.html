LIVE WEB APPLICATION

World Clock & Time Zones 🌍

Compare live local times around the world, explore time differences and find a suitable meeting time. Daylight saving time is handled automatically.

Your cities are saved on this device. Times update every second.

MEETING PLANNER

Compare a meeting time

Choose a date and time in one city to see the equivalent local time in all your selected cities.

About this project

Built with HTML, CSS and vanilla JavaScript using the browser's Internationalization API (Intl.DateTimeFormat). No API key or server required. Time zones use IANA identifiers and account for daylight saving changes.
