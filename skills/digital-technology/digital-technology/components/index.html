Computer Components

Datamaskinens komponenter · VG1 IM

Learning objectives

  • Explain motherboard and processor using a practical example.
  • Explain memory and storage using a practical example.
  • Explain graphics and expansion using a practical example.
  • Explain power and cooling using a practical example.
  • Explain troubleshooting using a practical example.

Motherboard and processor

The motherboard connects components. The CPU executes instructions; cores allow multiple streams of work. Clock speed alone does not determine performance.

Memory and storage

RAM holds active data temporarily. SSDs and HDDs retain files without power. More RAM helps when many applications compete for memory.

Graphics and expansion

A GPU processes graphics and parallel computation. Expansion slots and ports connect additional hardware and peripherals.

Power and cooling

A power supply delivers suitable voltages. Cooling transfers heat away from components. Excessive heat can reduce performance.

Troubleshooting

Check symptoms, connections and temperatures, then test one change at a time. Back up files before repairs; follow electrical safety guidance.
