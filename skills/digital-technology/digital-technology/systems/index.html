Computer Systems

Datasystemer · VG1 IM

Learning objectives

  • Explain input, processing, output and storage using a practical example.
  • Explain hardware and software using a practical example.
  • Explain operating systems using a practical example.
  • Explain logic and instructions using a practical example.

Input, processing, output and storage

A computer receives input, processes instructions, produces output and may store information. A camera app uses all four stages.

Hardware and software

Hardware is physical equipment. Software is instructions and data. Firmware is software stored in a device to control its basic operation.

Operating systems

An operating system manages memory, files, devices and processes, and supplies interfaces for applications.

Logic and instructions

Digital circuits use logic gates. A processor repeatedly fetches, decodes and executes instructions. AND requires both inputs to be true; OR requires at least one.
