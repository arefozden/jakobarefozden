🖧 Digital Technology & IT Infrastructure

Core topics in digital technology, communication, networking and security.

Topics & capabilities

Digital Technology

Hardware and software, computer components, operating systems, binary data, digitalisation and how digital systems work.

Digital systems represent information using bits. Eight bits form a byte. The CPU executes instructions, RAM holds active data, and SSD storage retains files when power is off. An operating system manages hardware and provides services to applications.

Practical example

Binary 1010 = 8 + 2 = 10 (decimal).
1 byte = 8 bits.
RAM and SSD serve different purposes.

Try it yourself

Identify the CPU, RAM and storage on a computer and explain their roles.

Digital Communication

From telephony and circuit switching to packet switching, ARPANET, internet infrastructure and digital communication.

Traditional circuit-switched communication reserves a connection for a conversation. Packet-switched networks divide data into packets that share network capacity. ARPANET helped develop packet networking; the internet connects networks using common protocols. TCP provides reliable ordered delivery, while IP addresses and routes packets.

Practical example

Browser → DNS lookup → IP connection → HTTPS request → response

Try it yourself

Draw the path of a web request and explain why packets need addressing.

Local Networks

LAN and WAN, network topologies, routers, switches, Wi-Fi, IP addresses, DNS, DHCP and domains.

A LAN connects devices in a limited area; a WAN connects networks over larger distances. Switches forward frames within a network and routers forward packets between networks. DHCP supplies network settings, DNS resolves names, and Wi-Fi provides wireless access.

Practical example

ipconfig /all
nslookup example.com
ping 127.0.0.1

Try it yourself

Draw a home network with router, switch and clients. Identify the default gateway and DNS server.

Cybersecurity & Digital Safety

Threats and vulnerabilities, phishing, malware, passwords, multifactor authentication, backup, privacy, GDPR and responsible digital behaviour.

Confidentiality, integrity and availability are core security goals. Phishing exploits trust, malware harms systems, and weak passwords increase account risk. Use unique passwords, MFA, updates and tested backups. GDPR requires lawful and appropriate handling of personal data.

Practical example

Example: verify a suspicious message through a known contact channel instead of clicking its link.

Try it yourself

Create a security checklist for a fictional school computer; do not collect real passwords.

Practical Learning

Network diagrams, troubleshooting exercises, short investigations, posters, presentations and documentation.

Practical learning connects terminology to observable behaviour. Document the initial problem, test one possible cause at a time, record results and explain the solution. Use diagrams and screenshots without exposing private information.

Practical example

Problem → hypothesis → test → result → conclusion

Try it yourself

Investigate a connection problem in an authorised lab environment and write a short report.
