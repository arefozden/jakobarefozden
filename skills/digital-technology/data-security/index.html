LESSON 01

Security principles

Understand

Confidentiality restricts access, integrity protects accuracy, and availability keeps services usable. A school grade database needs all three: only authorized people can see grades, changes must be correct, and staff must be able to access it.

Try it yourself

Classify three failures of a school system using the CIA model.

Knowledge check: Which principle is affected when a server goes offline?

Availability.

LESSON 02

Threats and risk

Understand

A threat is a potential cause of harm; a vulnerability is a weakness; risk combines likelihood and consequence. Malware includes ransomware, spyware and trojans. Updates reduce known vulnerabilities but cannot eliminate all risk.

Try it yourself

Make a risk table for a fictional laptop with likelihood and impact from 1 to 5.

Knowledge check: Why is an outdated browser a vulnerability?

Known weaknesses may remain unpatched.

LESSON 03

Authentication

Understand

Authentication establishes identity; authorization determines permitted actions. Unique long passwords and multifactor authentication reduce account takeover. A password manager helps avoid reuse.

Try it yourself

Design a fictional account protection checklist. Never enter real passwords into classroom tools.

Knowledge check: Does MFA make phishing impossible?

No; it reduces risk but some phishing can bypass it.

LESSON 04

Social engineering

Understand

Phishing uses deceptive messages to obtain information or induce unsafe actions. Check the sender domain, unexpected urgency and destination links. Verify requests through a separate trusted channel.

Try it yourself

Write a safe fictional phishing example and annotate warning signs.

Knowledge check: What should you do with an unexpected payment request?

Verify independently before acting.

LESSON 05

Encryption and backups

Understand

Encryption makes data unreadable without appropriate keys. HTTPS protects traffic in transit, not the trustworthiness of a website. Backups are separate recoverable copies; test restoration. The 3-2-1 strategy uses three copies, two media types and one offsite copy.

Try it yourself

Plan a backup for a fictional media project and test restoring a harmless file.

Knowledge check: Is synchronization alone a reliable backup?

No, deletion or corruption may synchronize too.

LESSON 06

Incident response

Understand

Report suspicious activity promptly, follow local procedures, isolate affected equipment if instructed, preserve evidence and recover from verified backups. Least privilege limits damage.

Try it yourself

Create a response flowchart for a fictional ransomware incident.

Knowledge check: Why report quickly?

To limit harm and enable coordinated response.
