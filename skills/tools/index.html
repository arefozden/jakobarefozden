Git & GitHub

Commits, branches, collaboration, pull/push workflows and GitHub Pages publishing.

Git tracks changes locally; GitHub hosts repositories for collaboration. A commit records a snapshot, a branch isolates work, and a pull request supports review. Pull before starting on a clean branch and inspect changes before committing.

Practical example

git status
git pull --ff-only
git add .
git commit -m "Update documentation"
git push

Try it yourself

Make a small change in a test repository and inspect its commit history.

VS Code

Editor extensions, integrated terminal, file organisation and debugging.

VS Code provides file navigation, syntax highlighting, an integrated terminal and debugging. Open the project root so relative paths are predictable. Use a local HTTP server to test pages that fetch resources.

Practical example

python -m http.server 8000

Try it yourself

Open a static project locally and locate an intentional broken file path.

Developer tools

Browser inspector, console, network requests and troubleshooting.

Browser DevTools help diagnose rendering and network problems. Elements shows the DOM and applied CSS; Console displays script errors; Network shows request status, response and timing. CORS restrictions must be addressed by the resource provider or an appropriate server architecture.

Practical example

console.log("Starting request");
console.table([{ city: "Oslo", selected: true }]);

Try it yourself

Use Network to inspect a request from an existing API application.

Documentation

README files, project descriptions, source references and structured handover notes.

Good documentation explains the problem, installation, usage, architecture, known limitations and sources. A README should allow another developer to run the project without guessing. Never include credentials or private data.

Practical example

# Project name
## Purpose
## How to run
## Technologies
## Limitations

Try it yourself

Write a README for a small browser application.
