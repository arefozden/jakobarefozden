Koble JavaScript til HTML

En ekstern JavaScript-fil kan kobles til HTML-siden rett før </body>. 

<script src="script.js"></script>

console.log()

Bruk console.log() for å skrive informasjon til konsollen. Dette er nyttig når du tester og feilsøker kode. 

console.log("Hei verden!");

let navn = "Ola";

console.log(navn);

let og const

Variabler brukes til å lagre informasjon. let brukes når verdien kan endres, mens const brukes når variabelen ikke skal tilordnes en ny verdi. 

let alder = 16;

const skole = "Mailand vgs";

alder = 17;

Datatyper

JavaScript kan lagre forskjellige typer data, for eksempel tekst, tall og true/false-verdier. 

let navn = "Sara";       // String

let alder = 16;          // Number

let elev = true;         // Boolean

let ingenting = null;    // Null

Operatorer

Operatorer kan blant annet brukes til matematiske beregninger. 

let a = 10;
let b = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Sammenligning

Sammenligninger gir resultatet true eller false. 

let alder = 18;

console.log(alder === 18);
console.log(alder > 15);
console.log(alder < 20);

if / else

Med if og else kan programmet ta valg basert på en betingelse. 

let alder = 18;

if (alder >= 18) {
    console.log("Du er myndig.");
} else {
    console.log("Du er under 18 år.");
}

Funksjoner

En funksjon samler kode som kan brukes flere ganger. 

function siHei() {
    console.log("Hei!");
}

siHei();

Funksjon med parameter

Parametere gjør det mulig å sende informasjon inn i en funksjon. 

function siHei(navn) {
    console.log("Hei " + navn);
}

siHei("Sara");

Arrays

Et array kan lagre flere verdier i én variabel. 

const fag = [
    "HTML",
    "CSS",
    "JavaScript"
];

console.log(fag[0]);

for-løkke

En løkke brukes når kode skal gjentas flere ganger. 

for (let i = 0; i < 5; i++) {
    console.log(i);
}

forEach()

forEach() kan brukes til å gå gjennom alle elementene i et array. 

const fag = [
    "HTML",
    "CSS",
    "JavaScript"
];

fag.forEach(fagNavn => {
    console.log(fagNavn);
});

DOM

DOM gjør det mulig for JavaScript å finne og endre innhold på en nettside.

getElementById()

getElementById() finner et HTML-element ved hjelp av elementets ID. 

const overskrift =
    document.getElementById("overskrift");

overskrift.textContent =
    "Ny overskrift";

querySelector()

querySelector() kan finne et element ved hjelp av en CSS-selector. 

const knapp =
    document.querySelector(".button");
↑ Til toppen

Events

JavaScript kan reagere på det brukeren gjør, for eksempel når brukeren klikker på en knapp.

addEventListener()

En event listener venter på en bestemt hendelse og kjører kode når hendelsen skjer. 

const knapp =
    document.querySelector("#min-knapp");

knapp.addEventListener("click", () => {
    console.log("Knappen ble klikket!");
});

Endre CSS med JavaScript

JavaScript kan legge til eller fjerne CSS-klasser på HTML-elementer. 

const boks =
    document.querySelector(".boks");

boks.classList.add("active");

Enkel debugging

Hvis JavaScript ikke fungerer, kan du starte med å åpne utviklerverktøyene i nettleseren og se etter feilmeldinger i Console. 

console.log("Programmet starter");

console.log(verdi);

Bruk console.log() underveis for å kontrollere hvilke verdier programmet arbeider med.
