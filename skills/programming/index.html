Python

Variables, conditions, loops, functions, collections, input validation and small applications.

Python uses indentation to define blocks. Functions package reusable behaviour; lists and dictionaries organise data. Convert user input carefully and handle exceptions at the boundary of the program.

Practical example

def total(price, count):
    if price < 0 or count < 0:
        raise ValueError("Negative input")
    return price * count

print(total(120, 3))

Try it yourself

Extend the function with a discount for five or more items.

C#

Object-oriented programming concepts, types, classes and application structure.

C# is a statically typed language in the .NET ecosystem. Classes group data and behaviour; interfaces express contracts. Explicit types help detect incompatible operations before execution.

Practical example

public class Product
{
    public decimal Price { get; set; }
    public int Quantity { get; set; }
    public decimal Total => Price * Quantity;
}

PHP

Server-side web development, forms and application logic.

PHP normally runs on a server and generates responses to browser requests. Validate input on the server, escape output and use prepared statements for database operations. GitHub Pages cannot execute PHP.

Practical example

<?php
$name = $_GET["name"] ?? "Guest";
echo htmlspecialchars($name, ENT_QUOTES, "UTF-8");
?>

SQL

Relational databases, queries, filtering, joins and data modelling.

Relational databases store records in tables. Primary keys identify rows and foreign keys link tables. SELECT retrieves data, WHERE filters it and JOIN combines related records.

Practical example

SELECT name, price
FROM products
WHERE price < 500
ORDER BY price ASC;
