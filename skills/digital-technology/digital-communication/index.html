LESSON 01

Signals and transmission

Understand

Information travels as electrical, optical or radio signals. Copper uses electrical signals, fibre uses light and wireless uses electromagnetic waves. Noise and attenuation can reduce signal quality.

Try it yourself

Compare copper, fibre and Wi-Fi for a school building.

Knowledge check: Which medium uses light?

Optical fibre.

LESSON 02

Telephone and switching

Understand

Traditional telephone networks reserved a circuit for a call. Packet switching shares links by dividing messages into packets. ARPANET helped demonstrate packet networking and TCP/IP later connected heterogeneous networks.

Try it yourself

Draw two users sharing a packet-switched link and compare with dedicated circuits.

Knowledge check: Why can packet switching use capacity efficiently?

Multiple conversations can share the same link.

LESSON 03

Internet and Web

Understand

The Internet is a network of networks; the Web is a service using HTTP and HTTPS. URLs identify resources, browsers request them, and servers respond. Email and DNS are other Internet services.

Try it yourself

Label the steps from typing a URL to seeing a web page.

Knowledge check: Are Internet and Web identical?

No, the Web is one service on the Internet.

LESSON 04

Protocols and layers

Understand

Application protocols such as HTTP use transport protocols such as TCP or UDP. IP addresses and routes packets, while Ethernet and Wi-Fi carry frames locally. TCP provides ordered reliable delivery; UDP has less overhead but no built-in delivery guarantee.

Try it yourself

Draw a four-layer TCP/IP model with one example per layer.

Knowledge check: Which protocol routes packets between networks?

IP.

LESSON 05

Bandwidth and latency

Understand

Bandwidth describes transfer capacity, throughput is achieved rate, and latency is delay. A 100 MB file contains 800 megabits using decimal units; at 20 Mbps its ideal transfer takes 40 seconds. Real transfers have overhead.

Try it yourself

Compare estimated and measured transfer times using a non-sensitive file.

Knowledge check: Can high bandwidth coexist with high latency?

Yes.
