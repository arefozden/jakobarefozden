NDLA topic reference
LESSON 01

File management

Understand

Use meaningful filenames, consistent project directories and clear versions. File extensions indicate formats; converting formats normally requires appropriate software, not renaming extensions.

Try it yourself

Organize a sample project into assets, source and documentation folders.

Knowledge check: Does renaming .png to .jpg convert the image?

No.

LESSON 02

Shortcuts and tools

Understand

Common shortcuts include Ctrl+C copy, Ctrl+V paste, Ctrl+Z undo and Ctrl+S save; macOS often uses Command. VS Code supports search, formatting and a terminal. Browser developer tools inspect HTML, CSS and network requests.

Try it yourself

Create a shortcut cheat sheet and inspect a practice page.

Knowledge check: Which tool can show failed web requests?

Browser developer tools Network panel.

LESSON 03

Git and documentation

Understand

Git records project history; commits capture staged changes. Pull before collaborative work, review diffs and avoid committing credentials or unnecessary archives. README files explain setup and use.

Try it yourself

Make a small practice commit and write a README.

Knowledge check: What does git status show?

Working tree and staging status.

LESSON 04

Media and accessibility tools

Understand

Choose tools based on task: image editors for raster graphics, vector editors for scalable shapes, audio editors for sound and video editors for timelines. Use alt text, captions and adequate contrast.

Try it yourself

Export an accessible sample asset and document format choice.

Knowledge check: Why use SVG for simple icons?

It scales without pixelation.

LESSON 05

Sources and licences

Understand

Record author, title, source and licence for reused materials. Creative Commons licences have differing conditions; check each asset. Use original or appropriately licensed material and distinguish quotation from your own work.

Try it yourself

Create a source register for three hypothetical assets.

Knowledge check: Does online availability mean unrestricted reuse?

No.
