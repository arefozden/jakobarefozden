HTML & semantics

Document structure, forms, accessible markup and meaningful content.

Semantic HTML describes the purpose of content rather than its appearance. Use a single main landmark, logical headings, labelled form controls and descriptive links. Native buttons support keyboard interaction without extra scripts.

Practical example

<label for="city">City</label>
<input id="city" name="city" required>

CSS & responsive design

Layouts with Flexbox and Grid, design systems, media queries and mobile-first styling.

The box model separates content, padding, border and margin. Flexbox is useful for one-dimensional alignment; Grid handles rows and columns. Flexible units and media queries let layouts adapt to smaller screens.

Practical example

 .cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 250px), 1fr));
  gap: 1rem;
}

Try it yourself

JavaScript in the browser

DOM, events, asynchronous code, fetch(), JSON and localStorage.

JavaScript responds to events and updates the DOM. Asynchronous functions handle network requests without blocking the page. Use textContent for plain external data and localStorage for non-sensitive preferences.

Practical example

document.querySelector("button").addEventListener("click", () => {
  document.querySelector("#message").textContent = "Hello!";
});
