Topics & capabilities

Learning resources

Clear instructions, presentations, step-by-step exercises and digital materials.

A learning resource should state a clear objective, explain essential concepts, show an example and provide practice. Scaffolding can gradually move learners from guided examples to independent work.

Practical example

Objective → demonstration → guided practice → independent task → reflection

Try it yourself

Design a short introduction to HTML with one measurable learning objective.

Project-based learning

Hands-on assignments, collaboration, reflection and documentation.

Project-based learning turns a real problem into an assignment with clear requirements and milestones. Students can make design choices while documenting their decisions and testing their results.

Practical example

Brief → plan → prototype → implementation → testing → reflection

Try it yourself

Plan a three-page website assignment with a basic and an extension challenge.

Programming education

Teaching HTML, CSS, JavaScript and Python through approachable projects.

Begin with small programs that make input, processing and output visible. Introduce conditions, loops and functions through examples, then encourage learners to explain and modify their own code.

Practical example

name = input("Your name: ")
print("Hello", name)

Try it yourself

Ask learners to extend this program with a conditional greeting.

Technology understanding

Making digital systems, networking and cybersecurity understandable for learners.

Technology understanding connects hardware, software, communication and security to everyday experiences. Diagrams, simulations and supervised practical tasks help make abstract concepts concrete.

Practical example

Client → switch/router → network → server

Try it yourself

Have students explain the journey of a web request using a diagram.

Assessment & feedback

Competence goals, formative feedback and reflection on the learning process.

Formative assessment identifies current understanding and helps learners improve. Feedback should name what works, explain the gap and suggest a practical next step. Use relevant competence goals rather than judging only visual polish.

Practical example

What works? → What needs improvement? → What should happen next?

Try it yourself

Create feedback for a fictional student website with one strength and one actionable improvement.
