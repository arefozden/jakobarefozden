LESSON 01

Network devices and topology

Understand

A LAN connects devices in a limited area. A switch forwards frames locally using MAC addresses; a router connects networks; an access point connects wireless clients. Star topology connects devices to a central switch.

Try it yourself

Draw a classroom network with six PCs, switch, router and access point.

Knowledge check: Which device connects different IP networks?

Router.

LESSON 02

Cables and wireless

Understand

Ethernet over twisted pair offers stable wired connections; fibre supports long distances and high capacities. Wi-Fi shares radio spectrum and is affected by walls and interference. Use suitable encryption and separate guest access.

Try it yourself

Plan placement of an access point and cable routes.

Knowledge check: Why can Wi-Fi slow down in a crowded room?

Devices share radio capacity and may interfere.

LESSON 03

IP and subnet masks

Understand

IPv4 uses 32 bits. A subnet mask separates network and host bits. For 192.168.1.42/24 the network is 192.168.1.0 and broadcast is 192.168.1.255. A default gateway forwards traffic beyond the local network. IPv6 uses 128 bits.

Try it yourself

Calculate network and broadcast for three /24 addresses.

Knowledge check: What does /24 mean?

24 network-prefix bits.

LESSON 04

DHCP and DNS

Understand

DHCP can lease IP configuration including gateway and DNS server. DNS resolves names to records such as IP addresses. A domain name is a hierarchical name; an organizational directory domain is a separate identity management concept.

Try it yourself

Trace a new laptop joining a network and opening a website.

Knowledge check: Which service assigns IP configuration automatically?

DHCP.

LESSON 05

Network services and segmentation

Understand

Clients request services from servers. File sharing, printing and web hosting are examples. VLANs separate logical local networks; firewall rules control traffic. NAT can translate private IPv4 addresses at the network edge.

Try it yourself

Design a guest network separated from staff systems.

Knowledge check: Is NAT a substitute for a firewall?

No.

LESSON 06

Troubleshooting

Understand

Check link and Wi-Fi, then IP settings, gateway reachability, DNS and application service. Use ipconfig or ip addr, ping and nslookup in approved environments. A failed ping alone is not proof a host is down.

Try it yourself

Diagnose a fictional case where IP connections work but names fail.

Knowledge check: What should you investigate first in that case?

DNS configuration and resolution.
