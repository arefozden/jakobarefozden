LESSON 01

Operating systems and terminal

Understand

Operating systems manage resources and permissions. A terminal lets users execute commands. In Linux, pwd shows location, ls lists files and mkdir creates a directory. Work in a disposable practice folder.

Try it yourself

Create a practice folder and document commands; do not use administrator privileges.

Knowledge check: What does pwd show?

Current working directory.

LESSON 02

Server and virtual machines

Understand

A server provides services to clients. A virtual machine runs an isolated guest operating system on shared hardware. Snapshots can help roll back experiments but are not independent backups.

Try it yourself

Draw a host, guest VM, service and client diagram.

Knowledge check: Why use an isolated VM for training?

To reduce risks to production systems.

LESSON 03

WordPress setup

Understand

WordPress is a CMS requiring compatible PHP, database and web server infrastructure. In an approved local environment, install dependencies, create a database and restricted account, configure WordPress, update components and test access. Avoid publishing default credentials.

Try it yourself

Plan a local WordPress deployment and document requirements, setup and verification.

Knowledge check: What is the database used for?

Stores content and configuration.

LESSON 04

Streaming server setup

Understand

HLS distributes media through a playlist and short segments over HTTP. An encoder prepares media and a server delivers it; clients may select quality variants. A Linux lab can use an approved encoder and web server to serve generated HLS files locally.

Try it yourself

Draw the HLS pipeline and test a teacher-provided sample stream.

Knowledge check: What does an HLS playlist describe?

Media segments or available stream variants.

LESSON 05

Operations and documentation

Understand

Maintain updates, access control, backups, logs and a change record. Test recovery and record reproducible configuration steps without storing secrets.

Try it yourself

Create a service handover document with verification steps.

Knowledge check: Why document changes?

To support recovery and troubleshooting.
