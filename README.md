## Jakob Aref Øzden — Personal Website

Static personal website using HTML, CSS and JavaScript.

## Pages
Home · About · Projects · Skills · Blog · Contact · CV

## Run locally
Use VS Code Live Server or `python -m http.server 8000` and open http://localhost:8000. Do not open HTML using `file://`.

## GitHub Pages
Publish from `main` / `(root)` in Settings → Pages. All new site links use relative paths and support a repository project path. The legacy files under assets and blog remain for future use.
