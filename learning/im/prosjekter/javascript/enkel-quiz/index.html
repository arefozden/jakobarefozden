Enkel quiz

I dette prosjektet skal du lage en enkel quiz med HTML, CSS og JavaScript. Brukeren skal svare på spørsmål og få tilbakemelding på svaret.

Mål

Når du er ferdig med prosjektet, skal du kunne:

  • koble JavaScript til en HTML-side
  • bruke variabler
  • bruke if/else
  • lage en funksjon
  • hente et HTML-element med JavaScript
  • reagere på et klikk

Del 02

Oppdrag

Du skal lage en enkel quiz med minst ett spørsmål.

Brukeren skal:

  • lese et spørsmål
  • velge eller skrive et svar
  • trykke på en knapp
  • få beskjed om svaret er riktig eller feil

Når grunnversjonen fungerer, kan du utvide quizen med flere spørsmål og poeng.

Del 03

Krav

Prosjektet skal minst inneholde:

  • HTML
  • CSS
  • JavaScript i egen fil
  • minst ett spørsmål
  • minst ett input-felt eller svaralternativ
  • en knapp
  • en funksjon
  • if/else
  • tilbakemelding til brukeren

Legg til flere spørsmål, poengteller eller resultat på slutten.

Del 04

Steg for steg

1. Lag prosjektmappen

quiz/
│
├── index.html
├── style.css
└── script.js

2. Lag HTML

Lag spørsmål, input, knapp og et område der resultatet kan vises.

3. Koble JavaScript

<script src="script.js"></script>

4. Finn elementene

Bruk JavaScript til å finne input, knapp og resultatfelt.

5. Reager på klikk

Bruk addEventListener().

6. Kontroller svaret

Bruk if/else til å kontrollere om svaret er riktig.

7. Vis resultat

Endre teksten på siden slik at brukeren får tilbakemelding.

8. Test

Test både riktig og feil svar. Se etter feil i Console.

Del 05

Enkel kodeidé

Dette er et enkelt eksempel på logikken. Du kan bygge videre på det. 

const svar =
    document.querySelector("#svar");

const knapp =
    document.querySelector("#sjekk");

const resultat =
    document.querySelector("#resultat");


knapp.addEventListener("click", () => {

    if (svar.value === "Oslo") {

        resultat.textContent =
            "Riktig!";

    } else {

        resultat.textContent =
            "Prøv igjen.";

    }

});

Prøv først å forstå hva hver del gjør før du kopierer eller endrer koden.
