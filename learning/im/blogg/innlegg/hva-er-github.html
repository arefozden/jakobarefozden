Git & GitHub

Hva er GitHub?

GitHub er en plattform der du kan lagre, dele og samarbeide om kode.

27. august 2026

Hva brukes GitHub til?

GitHub brukes til å lagre kodeprosjekter på nettet. Et prosjekt på GitHub ligger vanligvis i et repository, ofte kalt et repo.

Du kan bruke GitHub både alene og sammen med andre. Det gjør det lettere å følge med på endringer og utviklingen i et prosjekt.

Hva er Git?

Git er et system for versjonskontroll. Det betyr at Git kan holde oversikt over endringer du gjør i filer og kode.

Git og GitHub er ikke det samme

Git er selve verktøyet for versjonskontroll, mens GitHub er en nettbasert tjeneste som bruker Git.

Hvorfor bruke GitHub?

  • Du har en kopi av prosjektet ditt på nettet.
  • Du kan se tidligere versjoner.
  • Du kan samarbeide med andre.
  • Du kan dele prosjektene dine.
  • Du kan publisere nettsider med GitHub Pages.

GitHub og IM Portal

IM Portal utvikles også som et GitHub-prosjekt. Når vi gjør endringer i nettsiden, kan vi lagre utviklingen gjennom commits og senere publisere siden med GitHub Pages.
