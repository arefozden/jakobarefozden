print()

print() brukes til å skrive tekst eller verdier til terminalen. 

print("Hei verden!")

Variabler

Variabler brukes til å lagre informasjon som programmet kan bruke senere. 

navn = "Sara"
alder = 16

print(navn)
print(alder)

Datatyper

Python kan arbeide med forskjellige typer data, for eksempel tekst, heltall, desimaltall og true/false-verdier. 

navn = "Sara"       # str

alder = 16          # int

hoyde = 1.72        # float

elev = True         # bool

Regneoperatorer

a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)

input()

input() brukes når programmet skal hente informasjon fra brukeren. 

navn = input("Hva heter du? ")

print("Hei " + navn)

Input med tall

Verdien fra input() er tekst. Hvis vi trenger et heltall, kan vi bruke int(). 

alder = int(
    input("Hvor gammel er du? ")
)

print(alder)

if

if brukes når programmet skal gjøre noe dersom en betingelse er sann. 

alder = 18

if alder >= 18:
    print("Du er myndig.")

if / else

alder = 16

if alder >= 18:
    print("Du er myndig.")
else:
    print("Du er under 18 år.")

if / elif / else

elif kan brukes når programmet skal kontrollere flere muligheter. 

poeng = 75

if poeng >= 90:
    print("Svært bra")
elif poeng >= 60:
    print("Bra")
else:
    print("Prøv igjen")

for-løkke

En for-løkke brukes når kode skal gjentas flere ganger. 

for tall in range(5):
    print(tall)

range()

range() kan brukes til å lage en serie med tall. 

for tall in range(1, 6):
    print(tall)

Dette skriver ut tallene fra 1 til 5.

while-løkke

En while-løkke fortsetter så lenge en betingelse er sann. 

tall = 1

while tall <= 5:
    print(tall)
    tall = tall + 1

Lister

En liste kan lagre flere verdier i én variabel. 

fag = [
    "HTML",
    "CSS",
    "Python"
]

print(fag)

Hente fra en liste

Det første elementet i en liste har indeks 0. 

fag = [
    "HTML",
    "CSS",
    "Python"
]

print(fag[0])

Legge til i en liste

append() legger til et nytt element på slutten av listen. 

fag = [
    "HTML",
    "CSS"
]

fag.append("Python")

print(fag)

Løkke gjennom en liste

fag = [
    "HTML",
    "CSS",
    "Python"
]

for fag_navn in fag:
    print(fag_navn)

Funksjoner

En funksjon samler kode som kan brukes flere ganger. 

def si_hei():
    print("Hei!")

si_hei()

Funksjon med parameter

En parameter gjør det mulig å sende informasjon inn i funksjonen. 

def si_hei(navn):
    print("Hei " + navn)

si_hei("Sara")

return

return brukes når en funksjon skal sende en verdi tilbake. 

def legg_sammen(a, b):
    return a + b

resultat = legg_sammen(5, 3)

print(resultat)

Enkel feilsøking

Når Python-koden ikke fungerer, bør du lese feilmeldingen i terminalen. Den forteller ofte hvilken linje problemet finnes på. 

print("Programmet starter")

navn = "Sara"

print(navn)

Vanlige feil

  • Feil innrykk i koden.
  • Manglende kolon etter if, for eller def.
  • Variabelnavnet er skrevet feil.
  • Tekst mangler anførselstegn.
  • Du prøver å regne med tekst i stedet for tall.

Bruk print() når du tester

print() kan brukes underveis for å kontrollere hvilke verdier programmet har. 

alder = 16

print("Alder før if:", alder)

if alder >= 18:
    print("Myndig")
else:
    print("Ikke myndig")
